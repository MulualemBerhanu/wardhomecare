ULeadRTH — PREMIUM PUBLIC WEBSITE

Build a modern, premium, production-quality public website for ULeadRTH.

PROJECT GOAL

ULeadRTH is a mental health / residential treatment and supportive care organization.

For this first phase, build ONLY the public-facing informational website.

This is NOT currently a web application.

DO NOT build:

* Login
* Sign up
* User accounts
* Patient portal
* Staff portal
* Dashboard
* Database
* Authentication
* Admin panel
* Client management system

Those capabilities may be added later.

For now, the goal is a beautiful, trustworthy, fast, responsive website that explains ULeadRTH, communicates its services and philosophy, and makes it easy for visitors to contact the organization.
